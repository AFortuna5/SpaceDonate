🚀 SPACEDONATE v2.0 — NOVA VERSÃO LANÇADA!

Após meses de desenvolvimento, a segunda versão do SpaceDonate está pronta para testar. Uma plataforma completa para streamers receberem donates via Pix sem sair da live.

---

🎯 O QUE MUDOU DESDE A ÚLTIMA ATUALIZAÇÃO:

✅ Autenticação segura com e-mail/senha
✅ Dashboard funcional com tudo que o streamer precisa
✅ Testes automatizados em 100% das telas
✅ Tratamento robusto de erros (sem mais "Resposta do servidor inválida")
✅ Sistema de alertas em tempo real via SSE
✅ Overlay animado pronto para OBS
✅ Conexão com YouTube e Twitch (OAuth)

---

🎬 AS 5 TELAS DO PROJETO:

1️⃣ PÁGINA INICIAL
- Landing page com visão do produto
- Preview do painel e funcionalidades
- Call-to-action para criar conta
- Links para testar overlay e donate

2️⃣ LOGIN & REGISTRO
- Autenticação com e-mail/senha segura
- OAuth com YouTube e Twitch
- Validações em tempo real
- Toggle de visibilidade de senha

3️⃣ DASHBOARD DO STREAMER
- Resumo: donates, alertas, status
- Links rápidos para donate e overlay
- Informações da conta (canal, email, criada em)
- Gerenciar conexões com plataformas
- Botão de logout

4️⃣ PÁGINA DE DONATE
- Seleção de valores (R$5, R$10, R$25, R$50, customizado)
- Campos: nome, email, mensagem
- Geração de Pix em QR code
- Contador de donates de hoje
- Design minimalista e responsivo

5️⃣ OVERLAY OBS
- Alertas em tempo real
- Design transparente para encaixar na cena
- Animações envolventes
- Modo teste (sem doações reais)
- Conexão SSE para atualização instantânea

---

🔧 TECNOLOGIAS:

Backend:
- Node.js puro (sem frameworks)
- PBKDF2 para criptografia de senhas
- OAuth 2.0 (YouTube + Twitch)
- Server-Sent Events para alertas ao vivo

Frontend:
- HTML5 + CSS3
- JavaScript vanilla
- Fetch API
- Design system limpo e consistente

Testes:
- Puppeteer para automação
- Validação de todas as telas
- Screenshots para inspeção
