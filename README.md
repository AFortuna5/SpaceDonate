# SpaceDonate

Projeto SaaS de doações para streamers.

## Stack
- TypeScript
- Next.js
- React
- Prisma ORM
- PostgreSQL
- Docker

## Instalação

```bash
npm install
```

## Rodar projeto

```bash
npm run dev
```

## Build produção

```bash
npm run build
npm start
```

## Banco de dados

Configure `.env`:

```env
DATABASE_URL=
JWT_SECRET=
```

## Deploy
- Frontend: Vercel
- Banco: Neon PostgreSQL
- Backend/API: Render
